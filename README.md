# 🚀 Mission Rennes 2 — Dossier de Candidature & Portfolio

Site interactif de présentation de parcours, veille technologique et dossier de candidature pour l'Université Rennes 2.

🌐 **Site en ligne (GitHub Pages)** : [https://mdintrich-bot.github.io/mission-rennes2/](https://mdintrich-bot.github.io/mission-rennes2/)

---

## 💻 Comment ouvrir et tester le projet simplement

### Option 1 : Directement dans votre navigateur (En ligne)
Cliquez simplement sur le lien GitHub Pages :
👉 **[https://mdintrich-bot.github.io/mission-rennes2/](https://mdintrich-bot.github.io/mission-rennes2/)**

*(Pour activer le déploiement sur GitHub : allez dans `Settings` > `Pages` > `Source: GitHub Actions`)*

---

### Option 2 : Lancer en local (Développement)

1. **Cloner ou télécharger le dépôt** :
   ```bash
   git clone https://github.com/mdintrich-bot/mission-rennes2.git
   cd mission-rennes2
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Démarrer le serveur de développement** :
   ```bash
   npm run dev
   ```
   Puis ouvrez l'adresse indiquée (ex: `http://localhost:5173/`).

---

### Option 3 : Tester la version de production en local

```bash
npm run build
npm run preview
```

---

## 🛠️ Stack Technique

- **React 19**
- **Vite** (bundler ultra rapide)
- **Framer Motion** (animations & transitions fluides)
- **Lucide React** (iconographie moderne)
- **CSS Vanilla sur mesure** (typographie, glassmorphism, grille interactive)
